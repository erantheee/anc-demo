# ANC 原理速查

## 1. 主动降噪做什么

ANC 用扬声器发出与噪声**反相、同幅**的声波，在空间某点发生相消干涉，使该点声压趋于零。
它不吸声、不隔声，本质是"在局部点用声波抵消声波"。

### 安静区（Zone of Quiet）

抵消只在误差麦克风所在点附近有效，范围约 λ/10：

| 频率 | 波长 λ | 安静区直径 λ/10 |
|---|---|---|
| 100 Hz | 3.4 m | ~34 cm |
| 500 Hz | 0.68 m | ~7 cm |
| 1 kHz | 0.34 m | ~3 cm |
| 3 kHz | 0.11 m | ~1 cm |

> 结论：低频（电机、空调压缩机）安静区大、ANC 收益高；高频（风扇气动噪声）
> 安静区只有几厘米，ANC 收益低，应交给被动方案（隔音罩、吸音材料）。

## 2. 3D 打印机噪声来源

| 来源 | 类型 | 频段 | ANC 可行性 |
|---|---|---|---|
| 步进电机 | 音调（步进频率 + 谐波） | 几十 ~ 几百 Hz | 高 |
| 冷却风扇 | 叶片频率音调 + 宽带 | 数百 Hz ~ kHz | 中（音调部分） |
| 结构共振/框架 | 窄带共振峰 | 低 ~ 中频 | 高 |
| 挤出机/运动噪声 | 宽带、间歇 | 中频 | 低 |

测量目标：用频谱把"音调成分"和"宽带成分"分开，量化音调占比。音调占比高 →
ANC 值得做；占比低且集中在高频 → 建议被动方案。

## 3. 前馈 FXLMS

经典前馈 ANC：参考麦克风 x(n) → 自适应滤波器 W(z) → 输出 y(n) → 扬声器 →
声学路径 S(z)（次级路径）→ 误差麦克风 e(n)。目标：最小化 E[e²]。

FXLMS 与 LMS 的区别：参考信号要先经过**次级路径估计 Ŝ(z)** 得到滤波参考 x'(n)，
再用于权重更新，否则环路不稳定。

```
w(n+1) = w(n) + μ · e(n) · x'(n)      x'(n) = Ŝ * x(n)
y(n) = wᵀ(n) · x(n)
e(n) = d(n) − Ŝ * y(n)                （d 为误差处期望信号）
```

本仓库 `app/anc/fxlms.py` 提供可离线模拟的 FXLMS 实现，验证收敛与降噪量。

## 4. 谐波消除（周期噪声）

步进电机、风扇叶片频率噪声近似周期信号。两种做法：

1. **基频估计 + 自适应谐波权重**：估计基频 f₀（自相关），对每个谐波 k·f₀ 用复权值
   LMS 跟踪幅度/相位，叠加反相输出。（`app/anc/harmonic.py`）
2. 对强周期噪声，这种方案对延迟不敏感（信号可预测），比纯宽带 FXLMS 更稳。

## 5. 延迟预算

| 噪声类型 | 允许总延迟（约） | 说明 |
|---|---|---|
| 宽带随机噪声 | ≤ 1 ms | 必须因果对齐，Pi 上几乎不可行 |
| 音调/周期噪声 | 3–10 ms 甚至更高 | 信号可预测，收敛相位后即可抵消 |

Pi 直跑 I2S（WM8960）+ ALSA 小 period：环路延迟可做到 3–10 ms，适合音调降噪。

## 6. 评估指标

- 误差麦克风处 ANC 开/关 dB 差（宽带 + 分音调峰值报告）。
- A 加权 SPL 差（人耳感知更相关）。
- 频谱前后对比（哪些峰值被压掉）。
- 听感 A/B（定性）。
